Режим работы

Применяется сразу и сохраняется после перезагрузки.

Логи загрузки

Работает со следующей загрузки. Выключить можно и из Windows: создай на EFI-SYSTEM пустой файл pinebook-nologs. sudo pinebook-collect работает всегда.

Разгон и андервольтинг

Меняет таблицы частот и напряжений в загрузчике, работает после перезагрузки. Если ноутбук после этого не загружается или зависает, удали файл pinebook-tune.scr с раздела EFI-SYSTEM карты (виден в Windows) — вернутся заводские значения.
